# Competitive Programming Library

競技プログラミングで使用する C++ テンプレートおよびライブラリ。

## Structure

- `template/`: 基本テンプレート、debug、乱数・テストデータ生成
- `library/`: アルゴリズム、データ構造、グラフ、数学、文字列などのコード

## Dependencies

`template/template.hpp` は AtCoder Library (ACL) の
`#include <atcoder/all>` を利用します。

ACL 本体はこのリポジトリには含めていません。

## Usage

提出コードにライブラリのコードを取り込む場合は、
AtCoder の生成AI対策ルールに従い、使用したコードの参照URLを
提出コードの該当箇所に記載してください。
